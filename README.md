# AI Video/Meeting Assistance

This project provides tools to analyze meeting transcripts and extract actionable insights using LangChain and Mistral AI.

## Features
- **Action Items Extraction**: Identify tasks, owners, and deadlines.
- **Key Decisions Extraction**: List all major decisions made during the meeting.
- **Open Questions Extraction**: Extract unresolved questions and follow-ups.

## Configuration
Make sure to create a `.env` file in the root directory and add your Mistral API key:
```env
MISTRAL_API_KEY=your_api_key_here
```
